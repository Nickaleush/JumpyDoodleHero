# Jumpy Doodle Hero

Jumpy Doodle Hero — это прототип Android-игры в жанре vertical jumping arcade. Игрок управляет персонажем, который прыгает вверх по платформам, собирает бонусы, избегает препятствий и старается набрать как можно больше очков.

Проект создан как мобильный игровой прототип с простой аркадной механикой, вертикальной ориентацией и офлайн-прогрессом.

## Основной смысл игры

Игрок должен подниматься как можно выше, прыгая по платформам. Чем выше персонаж забирается, тем больше очков получает игрок. На пути встречаются полезные бонусы и опасные препятствия.

Главная цель — продержаться как можно дольше, улучшить рекорд и открыть новые игровые элементы.

## Игровая механика

Основные действия игрока:

* движение персонажа влево и вправо;
* автоматические прыжки после касания платформы;
* сбор монет и бонусов;
* избегание опасных объектов;
* прохождение всё более сложных участков.

Персонаж постоянно стремится вверх. Игрок управляет горизонтальным перемещением, чтобы попадать на платформы и не падать вниз.

## Основные игровые объекты

В игре используются:

* обычные платформы;
* движущиеся платформы;
* исчезающие платформы;
* монеты;
* бонусы;
* препятствия;
* враги или опасные объекты;
* зона падения, при достижении которой игра заканчивается.

Набор объектов может расширяться при дальнейшей доработке проекта.

## Условия проигрыша

Игра заканчивается, если персонаж падает ниже видимой области экрана или сталкивается с опасным объектом, который завершает забег.

После проигрыша игрок видит результат, свой счёт и может начать игру заново или вернуться в главное меню.

## Экраны приложения

В прототипе реализованы основные экраны:

* Splash Screen;
* Onboarding;
* Main Menu;
* Game Screen;
* Result Screen;
* Shop;
* Achievements;
* Leaderboard;
* Settings;
* No Internet Screen.

## Главное меню

Главное меню является стартовой точкой приложения. С него игрок может перейти к основным разделам игры:

* Play — запуск игры;
* Shop — магазин игровых скинов или улучшений;
* Achievements — список достижений;
* Leaderboard — псевдо-рейтинг игроков;
* Settings — настройки музыки и звуков.

Также на главном экране отображается внутриигровая валюта игрока.

## Магазин

Магазин используется для покупки визуальных скинов и игровых улучшений за софт-валюту.

Возможные типы предметов:

* скины персонажа;
* новые фоны;
* улучшения бонусов;
* дополнительные визуальные эффекты.

Покупки сохраняются локально. После покупки выбранный предмет может быть активирован и использоваться в игре.

## Достижения

Экран достижений содержит список игровых целей, связанных с прогрессом игрока.

Примеры достижений:

* первый запуск игры;
* первый собранный бонус;
* достижение определённой высоты;
* сбор определённого количества монет;
* несколько успешных забегов подряд;
* открытие предметов в магазине.

Достижения работают офлайн и сохраняются локально.

## Лидерборд

Leaderboard реализован как псевдо-рейтинг без реального онлайна. В списке отображаются боты с заранее заданными именами и очками. Текущий игрок отображается как `You`.

Рейтинг нужен для создания ощущения соревнования и дополнительной мотивации улучшать результат.

## Настройки

На экране настроек доступны базовые переключатели:

* Music — включение и выключение фоновой музыки;
* Sound Effects — включение и выключение звуковых эффектов.

Настройки сохраняются локально и применяются при следующих запусках приложения.

## Технологический стек

Проект разработан под Android.

Основной стек:

* Kotlin;
* Android SDK;
* Android Gradle Plugin;
* Gradle Wrapper;
* XML Layouts;
* Fragment-based navigation;
* Custom View для игрового экрана;
* Canvas API для отрисовки игровой сцены;
* SharedPreferences / локальное хранилище для прогресса, валюты, настроек и покупок;
* AppCompat / AndroidX;
* ConstraintLayout.

## Архитектура

Проект построен по классической Android-структуре с разделением экранов по feature-модулям.

Основные части проекта:

* `MainActivity` — основная Activity приложения;
* fragments — отдельные экраны приложения;
* custom game view — игровая логика и отрисовка;
* repository / storage layer — сохранение прогресса, валюты и настроек;
* models — игровые модели магазина, достижений, лидерборда и прогресса;
* resources — изображения, цвета, строки, layout-файлы и drawable-ресурсы.

## Игровой экран

Игровой экран реализован через custom view. Он отвечает за:

* отрисовку персонажа;
* отрисовку платформ;
* движение камеры вверх;
* обработку столкновений;
* подсчёт очков;
* сбор монет и бонусов;
* проверку условий проигрыша;
* обновление состояния игры.

Canvas API позволяет быстро собрать прототип без подключения тяжёлого игрового движка.

## Safe Area

В проекте должна учитываться safe area, чтобы элементы интерфейса не перекрывались статус-баром, navigation bar и системными жестами.

Это особенно важно для современных устройств с gesture navigation и Android 15+.

## Статус проекта

Текущая версия является игровым прототипом. В ней реализуется базовая структура приложения, основные экраны и ключевая механика vertical jumping arcade.

Проект можно использовать как основу для дальнейшей доработки:

* подключения финальных Figma-ресурсов;

* добавления новых платформ и препятствий;
* настройки сложности;
* добавления музыки и звуков;
* расширения магазина;
* полировки UI;
* подготовки production-сборки.
